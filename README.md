# Limit Bell

Claude usage-limit reset reminder (Android, Capacitor).

## APK বানানোর নিয়ম
1. GitHub-এ নতুন repo বানান (যেমন `limit-bell`)।
2. এই ফোল্ডারের সব ফাইল (লুকানো `.github` ফোল্ডারসহ) repo-তে আপলোড করুন।
3. repo-র **Actions** ট্যাবে "Build Android APK" চলবে (৫–১০ মিনিট)।
4. শেষ হলে repo-র **Releases** থেকে `LimitBell.apk` ডাউনলোড করে ইনস্টল করুন।
